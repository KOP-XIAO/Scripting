# CMHK Usage — Scripting App 脚本

在 iOS **Scripting** App 内展示中国移动香港（CMHK / MyLink）账户的话费余额、流量、通话与账单日，并提供现代化视觉的主屏幕小组件。

## 文件结构

```text
cmhk-usage/
├── script.json       # 项目元信息（name/icon/color/version）
├── index.tsx         # App 内页面：分块设置页 + 子页面（账户/接口/起始页/诊断中心）
├── widget.tsx        # 主屏幕小组件（systemSmall / systemMedium）
├── app_intents.tsx   # 小组件「刷新」按钮的 AppIntent
├── cmhk.ts           # 数据层：登录、抓取、归一化、缓存（唯一需要校准的文件）
└── theme.ts          # 视觉主题（深色卡片 + 渐变流量环）
```

## 功能

- **小组件**：渐变流量环（剩余百分比）、欠费/余额、通话分钟、多流量桶明细与到期日、角落悬浮刷新按钮（small 右下角 / medium 左下角，不占内容行）；medium 左环右文间竖向分割线；到期日完整年月日显示（如 2026/10/06）。
- **App 内页**：按 Section 分块的主设置页（数据 / 登入 / 進階設定 / 工具 / 診斷 / 關於），高级内容收进子页面（账户密码、手动接口、起始页、诊断中心）；数据总览卡片、演示模式、小组件预览；打开即自动刷新，页面存活期间每 30 分钟续刷。
- **数据策略**：App 直连与页内捕获并行取数，必要时使用已保存凭据自动登录；失败保留缓存并报告原因。每次刷新记录来源、是否取得新响应及数值是否变化。小组件请求每 15 分钟重载，实际时间由 iOS 决定；组件只能复用有效会话直连，不能自行创建登录网页。较新 Scripting 版本可读取包含 HttpOnly 的 Cookie，旧版本使用 `document.cookie` 回退。

## 自动登录与取数验证

1. 在 App 的「進階設定 → 自動登入憑據」保存 CMHK 手机号与 MyLink 密码。凭据仅存本机 Keychain，仅发往 CMHK 官方登录页。
2. 关闭演示模式，返回主页面，点「验证自动登录并刷新」。无需先手动登录。
3. 验证使用隔离网页会话，只有观察到本次登录请求、登录成功确认及之后的用量响应，才显示「自动登录验证成功」。旧 Cookie、旧快照、手动接口和演示数据均不作为验证成功的依据。
4. 若未完成，打开「診斷中心」查看阶段，或导出诊断包。记录包括捕获通道、表单字段数量、登录请求是否发生、登录是否确认、用量是否捕获；不记录密码、Cookie 或输入值。验证码或待确认的条款需要手动处理。

App 正常刷新时，已保存凭据且没有会话，或确认会话过期，都会尝试自动网页登录。无提交进展时约 6 秒结束，自动登录阶段最多 15 秒。独立验证通过前，不能仅凭本地测试断言你的设备已能自动登录。

无需自动登录时，仍可使用「網頁登入 CMHK」手动登录并进入用量查询页。首次只想看界面，可使用演示模式。

## 权限与安全

- 凭据只存 iOS 系统 Keychain（按脚本隔离），永不写入日志/缓存文件。
- 全部接口均为**只读**（登录 + 查询），不对账户做任何写操作。
- 手机号在界面上默认打码显示。

## 安装到 iOS

方式任选：

1. **iCloud**：Scripting 开启 iCloud 同步后，把 `cmhk-usage` 文件夹放入 iCloud Drive 的 Scripting 目录。
2. **scripting-cli**（桌面实时同步调试）：见 Scripting 官方 Desktop CLI 文档。

添加小组件：主屏幕添加 Scripting 小组件 → 长按编辑 → 选择「CMHK Usage」。预览效果可先在 App 内点「预览小组件」。

## 已知边界

- 小组件渲染后进程即销毁，交互仅限「刷新」按钮（AppIntent）。
- 小组件有约 30MB 内存上限，本组件只用矢量图形与文字，远低于上限。
- 接口频率请保持克制（默认 30 分钟自动刷新 + 手动刷新）。
