# 行程提醒（Trip Reminder）

> ⚠️ **重要**：本项目原名 `train-reminder`（高铁提醒，v1.0.0）。如果设备上装有旧的
> 「Train Reminder / 高铁提醒」，请**先删除它**（它的远程更新地址已失效，永远不会再更新），
> 只保留本「Trip Reminder / 行程提醒」。


iOS [Scripting App](https://scriptingapp.github.io) 脚本：把**火车**与**航班**行程放到主屏幕小组件上——
车次/航班号、出发到达、出发时间倒计时、检票口/登机口、座位号、登机时间、乘客姓名。

## 数据来源与隐私

- **录入**：在 App 里选一张 12306 行程截图或航司行程/登机牌截图 → **本机 Vision 框架**识别
  → 自动判别火车/航班并填表 → 你核对后保存；也支持相机扫描与纯手填。
- **隐私**：脚本**不含任何网络请求**，行程只写入本机 Storage（`rail.*` 键）。
  截图在识别后即丢弃，不落盘、不上传，也不会同步到代码仓库或任何第三方位置。
  仓库里只有代码，测试用例全部是编造的假数据。
- 小组件不显示乘客姓名；App 内卡片支持完整、打码、隐藏三种模式。

## 支持字段

| 通用 | 火车专属 | 航班专属 |
|---|---|---|
| 号码、承运方/车型、出发到达、日期、出发/到达时间、历时、闸口、座位、乘客、备注 | 检票口、车厢、座别（二等座…） | 登机口、航站楼、登机时间、值机柜台、舱位（经济舱…）、行李转盘 |

## 文件结构

```text
trip-reminder/

│   └── theme-background.tsx # 图片 / 渐变背景
├── services/
│   ├── parse.ts         # 截图文本 → 结构化行程（火车/航班判别，纯函数可离线测试）
│   ├── ocr.ts           # 相册选图 + Vision 本机识别
│   ├── trips.ts         # 本机存储与「下一班」选择（火车航班混排）

├── utils/common.ts      # 版本号
└── tools/test-parse.cjs # 解析器离线断言（假数据，15 组）
```

## 使用

需要 iOS 18 或更新版本（使用原生底部标签页）。

1. 截一张 12306 行程详情图，或航司 App 的行程/登机牌截图。
2. 打开脚本 → **从截图识别** → 核对（识别错就手改，类型会自动判别也可手动切换）→ **保存行程**。
3. 长按主屏幕 → 添加 Scripting 小组件 → 选 **中号** 与本脚本。

## 归档与小组件（v1.3.0）

- 行程左滑可选择归档、删除、编辑。归档保留完整记录，退出当前行程和小组件候选。
- 点「查看归档记录」进入只读历史视图；清空未归档行程不会删除归档。
- 倒计时统一显示「4 天｜11 小时」；不足 24 小时时显示「4 小时｜38 分」。
- 时间表旁显示行程时长（如「｜1 小时 24 分」），检票口/登机口和座位用大字号突出。
- 已填历时优先；缺失时根据钟点差推算跨午夜时长。跨时区航班请填写实际历时。

## 主题与强调色（v1.5.0）

底部「首页」用于识别、录入与管理行程；「设置」集中提供外观预览、主题、强调色、乘客显示和版本信息。未保存的录入草稿在切换标签页后保留。

设置页可切换六套主题。首页与设置预览共用完整卡片，背景、正文、车次徽标与重点信息随选择立即变化。存在下一段行程时预览该行程；没有行程时使用明确标注的虚构示例，不写入行程记录。

| 主题 | 视觉 |
|---|---|
| 车票白 | 浅色票据风 |
| 夜行蓝 | 深蓝渐变 |
| 松林绿 | 深松绿渐变与浅绿重点文字 |
| 赛博朋克 | 夜城剪影、电路线条、扫描纹理、青色与警示黄 |
| 动漫风景 | 蓝天云朵、远山、列车与铁路插画 |
| 旅行手账 | 暖纸纹、地图等高线、虚线航线与指南针 |

强调色独立于背景主题保存，支持「跟随主题」及爱马仕橙、蒂芙尼蓝、普鲁士蓝、克莱因蓝、勃艮第红、祖母绿、鸢尾紫、香槟金。强调车次／航班号、倒计时、检票口／登机口和座位；深浅背景使用对应明度，保证文字清晰。小组件读取同一份主题与强调色偏好。

三套插画背景由 tools/build-theme-assets.py 生成，不读取截图或个人行程。文字区留白，
检票口和座位区降低装饰对比度。主题切换请求刷新小组件，实际刷新时间由 iOS 决定。
