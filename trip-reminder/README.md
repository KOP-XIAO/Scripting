# 行程提醒（Trip Reminder）

> ⚠️ **重要**：本项目原名 `train-reminder`（高铁提醒，v1.0.0）。如果设备上装有旧的
> 「Train Reminder / 高铁提醒」，请**先删除它**（它的远程更新地址已失效，永远不会再更新），
> 只保留本「Trip Reminder / 行程提醒」。


iOS [Scripting App](https://scriptingapp.github.io) 脚本：把**火车**与**航班**行程放到主屏幕小组件上——
车次/航班号、出发到达、出发时间倒计时、检票口/登机口、座位号、登机时间、乘客姓名。

## 数据来源与隐私

- **录入**：在 App 里选一张 12306 行程截图或航司行程/登机牌截图 → **本机 Vision 框架**识别
  → 自动判别火车/航班并填表 → 你核对后保存；也支持相机扫描与纯手填。
- **隐私**：脚本**不含任何网络请求**，行程只写入本机 Storage（`rail.*` 键）。
  截图在识别后即丢弃，不落盘、不上传，也不会同步到代码仓库或任何第三方位置。
  仓库里只有代码，测试用例全部是编造的假数据。
- 小组件不显示乘客姓名；App 内卡片支持完整、打码、隐藏三种模式。

## 支持字段

| 通用 | 火车专属 | 航班专属 |
|---|---|---|
| 号码、承运方/车型、出发到达、日期、出发/到达时间、历时、闸口、座位、乘客、备注 | 检票口、车厢、座别（二等座…） | 登机口、航站楼、登机时间、值机柜台、舱位（经济舱…）、行李转盘 |

## 文件结构

```text
trip-reminder/

│   └── theme-background.tsx # 图片 / 渐变背景
├── services/
│   ├── parse.ts         # 截图文本 → 结构化行程（火车/航班判别，纯函数可离线测试）
│   ├── ocr.ts           # 相册选图 + Vision 本机识别

├── utils/common.ts      # 版本号

```

## 使用

需要 iOS 18 或更新版本（使用原生底部标签页）。

1. 截一张 12306 行程详情图，或航司 App 的行程/登机牌截图。
2. 打开脚本 → **从截图识别** → 核对（识别错就手改，类型会自动判别也可手动切换）→ **保存行程**。
3. 长按主屏幕 → 添加 Scripting 小组件 → 选 **中号** 与本脚本。

## 归档与小组件（v1.3.0）

- 行程左滑可选择归档、删除、编辑。归档保留完整记录，退出当前行程和小组件候选。
- 点「查看归档记录」进入只读历史视图；清空未归档行程不会删除归档。
- 倒计时统一显示「4 天｜11 小时」；不足 24 小时时显示「4 小时｜38 分」。
- 时间表旁显示行程时长（如「｜1 小时 24 分」），检票口/登机口和座位用大字号突出。
- 已填历时优先；缺失时根据钟点差推算跨午夜时长。跨时区航班请填写实际历时。

## 主题与强调色（v1.5.3）

v1.5.3 为夜行蓝和奶油摩卡补充独立背景图片：夜行蓝使用月牙、星点、远山与夜间轨道；奶油摩卡使用暖纸纹理、奶油色层叠圆弧与咖啡杯印。装饰集中在右侧，文字区保持安静。主题缩略图、设置预览、首页卡片及大小号小组件均读取相同背景资源。已保存的主题与强调色继续沿用。

v1.5.2 将预览高度与裁切设置在外层 `VStack`，内部 `GeometryReader` 只测量宽度，卡片固定为 158 pt 高；强调色行改用 `automatic` 列表按钮样式。修正针对 v1.5.1 真机反馈中的预览压缩与只有色块可点问题。桌面编译和模拟状态测试已检查；完整预览及文字、空白区域点击仍需在 iPhone 上复验。

底部「首页」用于识别、录入与管理行程；「设置」集中提供外观预览、主题、强调色、乘客显示和版本信息。未保存的录入草稿在切换标签页后保留。

设置页可切换六套主题。首页预览、设置预览与实际中号小组件共用渲染组件，保持字号、间距、三栏布局与背景一致；App 内两处预览使用同一个 158 pt 高的容器，乘客姓名显示在首页预览下方，遵循完整、打码、隐藏设置。主屏幕宿主尺寸和 iOS 显示模式仍可能影响效果。设置页存在下一段行程时预览该行程；没有行程时使用明确标注的虚构示例，不写入行程记录。

| 主题 | 视觉 |
|---|---|
| 车票白 | 浅色票据风 |
| 夜行蓝 | 深蓝夜景、月牙星点、远山与轨道，冰蓝重点文字 |
| 奶油摩卡 | 暖纸纹理、奶油色圆弧与咖啡杯印，可可棕正文与摩卡重点文字 |
| 赛博朋克 | 夜城剪影、电路线条、扫描纹理、青色与警示黄 |
| 动漫风景 | 蓝天云朵、远山、列车与铁路插画 |
| 旅行手账 | 暖纸纹、地图等高线、虚线航线与指南针 |

强调色独立于背景主题保存，支持「跟随主题」及爱马仕橙、蒂芙尼蓝、普鲁士蓝、克莱因蓝、勃艮第红、祖母绿、鸢尾紫、香槟金。强调车次／航班号、倒计时、检票口／登机口和座位；深浅背景使用对应明度，保证文字清晰。强调色选项整行可点击，包括文字和空白区域。小组件读取同一份主题与强调色偏好。原松林绿的已存偏好自动沿用为奶油摩卡。

五套插画背景由 tools/build-theme-assets.py 生成，不读取截图或个人行程。文字区留白，
检票口和座位区降低装饰对比度。主题切换请求刷新小组件，实际刷新时间由 iOS 决定。


## 自动归档、分页与座位隐私（v1.5.4）

- 行程到达后自动归档，按实际历时处理跨午夜及超过 24 小时的行程。没有可用到达时间或历时时，保留至出发日结束；日期或出发时间不完整时保留，等待补全。
- 打开脚本、页面每 30 秒刷新或小组件加载时检查归档。脚本关闭后不会持续运行，主屏幕刷新时间由 iOS 决定。
- 「查看归档记录」进入独立子页面，可用系统返回按钮回到首页；归档仍保留完整记录。
- 首页有多个未归档行程时，可以左右滑动预览，最近一段有效行程排在首位。滑动预览不改变小组件的行程选择。
- 设置中的「座位号」按钮独立控制车厢和座位号的显示，适用于首页卡片、列表、归档、设置预览及中号小组件；保留座别，编辑表单仍显示原始值。乘客姓名设置独立保留。
- 服务回归测试：`NODE_PATH=<含 esbuild 的 node_modules> node tools/test-trips.cjs`，覆盖到达边界、跨日、日期兜底、无效日期、归档保留、小组件选择、存储失败重试和座位隐私。

桌面逻辑测试和 TSX 编译已检查；原生分页手势、子页面返回及主屏幕刷新仍需在 iPhone 上验证。

## 首页预览统一（v1.5.5）

- 首页与设置页共用固定 158 pt 高的预览容器，内部直接使用实际中号小组件渲染器，统一字号、三栏布局、警示色和背景。
- 多行程继续左右分页；乘客姓名放在首页预览下方，保留完整、打码、隐藏三种模式。座位隐藏开关继续传递给预览。
- App 与小组件 TSX 编译、8 组服务回归及模拟组件的尺寸、渲染一致性、隐私参数检查通过。未连接 iPhone，原生分页及主屏幕显示仍需真机复验。
